# Code of Conduct

This project adopts the Contributor Covenant Code of Conduct, version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

Be respectful, constructive, and considerate. Harassment, discrimination, threats, and publishing
another person's private information are not acceptable.

Until a dedicated conduct address is published, report incidents privately to the repository owner
through the hosting platform. Reports will be reviewed promptly, kept confidential to the extent
possible, and handled in proportion to their severity.
