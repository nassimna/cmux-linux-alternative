Atlas Δ — the actual implementation diff

Everything above is already in the codebase. Shipping Atlas is these changes, all inside the existing token system:

Add

  • Δ1 .workspace-when — relative timestamp, mono 10px muted, right edge of name line (data from workspace last-activity)
  • Δ2 attention/idle indicator states — amber --aw-color-attention dot + one 11px alert line when data-attention='action-required'; idle dots use border-strong with no halo
  • Δ3 .workspace-hover-actions — actions overlay on hover with a 12px gradient fade; drop the permanent 76px right padding on .workspace-row / .workspace-details (→ 9px)
  • Δ4 14px left indent on meta/alert/chip rows so text aligns under the name (7px dot + 7px gap)
  • Δ5 .workspace-branch — inline branch in the directory row; keep the bordered .workspace-git-status pill only for dirty/ahead/behind states
  • Δ6 chips carry a tab-kind icon — terminal chips show the shell/process name, browser chips show the host (from the tab’s content.kind)
  • Δ7 .workspace-group-count — collapsed group headings show their workspace count, mono 10px muted
  • Ordering: Pinned section first, then user groups (existing group.* + collapse), then ungrouped workspaces under “Recent” sorted by last activity

Remove / conditionalize

  • “Status unavailable” text — render runtime status only when actionable (Δ2); workspaceGitStatusLabel fallback (WorkspaceShell.tsx:2585) returns nothing instead
  • Tab chips on unselected cards (Δ6) — chips render only under data-selected='true'
  • “Saved layouts / Save selection / Import” sidebar block (.saved-layouts-panel, styles.css:1179) — layouts move to the ⌘K palette and the heading’s overflow menu
  • Branch icon row with “—” when no branch — omit the row entirely

Sharp vs rounded — the exact cost of switching

Because the chrome reads every corner through var(--aw-radius-*), the rounded variant is a 4-line token change in tokens.css plus 2 hardcoded-sharp spots, with 2 optional “modern” accents. Nothing else moves — layout, metrics, and colors are identical.
