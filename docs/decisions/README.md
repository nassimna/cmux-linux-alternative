# Architecture decisions

Architecture decision records capture durable choices that affect protocol, persistence, security
boundaries, plugins, or major UI architecture.

Use a four-digit sequence, a short kebab-case title, and the sections: Context, Decision,
Consequences, and Alternatives considered.

Open an architecture or protocol RFC before proposing a decision that changes a durable boundary.
